# Pipeline de Eventos de Cliques

Simulação de tracking de eventos (cliques/visualizações) em Java com Spring Boot: um producer gera eventos no Kafka, um consumer agrega e grava os resultados no MongoDB, e um endpoint expõe as métricas agregadas.
